The module seems to be really well architectured I have run a security and code quality scan, then I have fix some things and update some documentation, the module after that works well
 
 
 
What was fixed
 
Critical
1. Ingest authz bypass — IngestController now rejects payloads whose market differs from the HMAC-verified X-Hrefl-Market header (403), plus a 500-records/request cap. New kernel test covers the mismatch.
2. MySQL install failure — unique key on url varchar(2048) is now a 191-char prefix key (comment documents the ceiling and the url_hash upgrade path).
3. Store wipe — AlternatesConsumer no longer calls replaceAll([]) when every page fails validation; last known-good alternates survive.
 
Security
4. secretFor() fails closed: unknown markets get no secret, a configured-but-unresolvable key_name no longer falls through to the shared env secret.
5. HMAC canonical string now covers the query string (v2: METHOD\nPATH\nQUERY\nTS\nsha256(body)) — client signer, hub check, and tests updated in lockstep; replay limitation documented.
6. import.csv POST route now requires _csrf_request_header_token.
7. CsvImportForm uses managed_file + FileExtension validator (temp file deleted after use); drupal:file added as dependency.
8. ServeController referer-style ?market= fallback deleted — market comes only from the signed header.
 
Correctness
9. Queue worker now processes its payload: publishes the one changed entity, retires deleted/unpublished ones (indexable: 0); publish failures propagate so the queue retries.
10. Cron client publish uses a nid cursor (collectNext()) — sites of any size fully sync.
11. Hub match pass is fair: new last_matched column (schema + update 10005), never-matched rows first — no more repeated LLM spend on the same 200 rows.
12. embedPass() embeds only members missing a vector (left join) instead of the same first 200.
13. Re-ingest no longer downgrades confirmed/rejected members (automation can refresh data, not status).
14. CsvImporter parses with fgetcsv() over a stream — quoted multi-line titles round-trip.
15. Validator accepts zh-Hans, zh-Hant-TW, es-419 with proper BCP 47 case normalization.
16. cosine() returns 0 for mismatched dimensions.
 
Caching
17. Selector endpoint: referer fallback removed (400 without ?url=), now a CacheableJsonResponse with url.query_args:url context + store tags.
18. Block: strips query string before lookup, empty result carries full #cache, aria-label translated.
19. New store-wide hrefl_alternates tag: pages/blocks rendered before their group exists get invalidated on the next pull (AlternatesStore invalidates it on every swap).
20. Misc: LinkHeaderSubscriber skips non-200s and strips query strings; update hooks renumbered to 10xxx; umbrella hrefl.info.yml is hidden: true; typed Registry
