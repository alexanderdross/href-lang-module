How to read it (v2). Each backend's Collector sends page inventory + matching signals to the hub (①). The Mapping Engine resolves equivalence in tiers - deterministic keys/glossary (A), cross-lingual embeddings (B), and an LLM (Copilot or Anthropic, both supported) that adjudicates - and can translate titles/URLs to locate equivalents for - ambiguous candidates (C, ②) - then a confidence router auto-confirms the safe matches, sends the middle band to editor review (③), and holds the rest. Editors' decisions feed a learning loop that grows the glossary and tunes thresholds. The Registry is the versioned source of truth; the Distributor pre-computes each backend's reciprocal alternates and pushes them to a local cached store (④), which the Emitters (⑤) and the crawlable, no-redirect selector read. The Monitor continuously validates coverage, drift, and broken links. Nothing calls across backends at request time.
